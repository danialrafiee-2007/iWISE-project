## Provenance

- RAGTruth: ParticleMedia/RAGTruth @ c103204b (MIT); official test split kept as the locked test set
- Dev: 10% of RAGTruth train sources per task, chosen by hash of source id (seed tg-dev-v1)
- HaluEval: RUCAIBox/HaluEval @ b7253db3 (MIT); 500 question groups per task (seed tg-subset-v1); 'general' excluded (no source documents)
- External dev (xdev_halueval_*): the next 250 groups per task in the same ranking, disjoint from the locked HaluEval files
- AgentHallu: liuxuannan/AgentHallu @ 9ffe8bc8 (CC BY 4.0); one third of questions (seed tg-agent-v1) as dev, the rest locked; reference answers and solution notes dropped
- Locked files live in data/processed/locked and may only be evaluated with --final
