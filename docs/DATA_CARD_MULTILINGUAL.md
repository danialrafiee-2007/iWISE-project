## Provenance

- RAGTruth translated by KRLabs with Gemma 3 27B (MIT): ragtruth-es-translated @ 39d88100, ragtruth-fr-translated @ 95d0aa3e, ragtruth-cn-translated @ 1f3db52b; train files only (their test files translate the locked RAGTruth test set)
- Rows matched to English RAGTruth train by order; dev = the English dev's sources. Sampled by source (seed tg-multilingual-v1): 25 train and 20 dev sources per task, the same ones in every language; multilingual_dev_en holds those sources' English responses (ragtruth_en), only to compare with the English engine
- PsiloQA @ 375c3321 (CC BY 4.0), ar, es, fr, zh only; spans labelled by GPT-4o, not by people; 300 train articles per language (articles also in dev or test dropped: 1042); validation as dev without the articles it shares with test (65 answers dropped); test locked
- XQuAD @ 7d30520c (CC BY-SA 4.0): controlled edits of the same 300 questions in en, ar, es, ru, zh (the answer's context sentence, and the same sentence with its number plus one or another question's answer); synthetic, evaluation only, never used for training or thresholds
- Locked files live in data/processed/locked and may only be evaluated with --final
