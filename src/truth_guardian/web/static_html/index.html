Truth Guardian

Truth Guardian checks an AI's answer before you rely on it. For text, it tests every sentence against your documents or against sources it finds itself (Wikipedia, Wikidata, web search and scholarly works) and labels each source as supporting, contradicting or unrelated. For images and recordings, a local model reads the file and a free online model reads it again; the Guardian compares the two readings sentence by sentence. The result is a verdict, grounded or hallucinated, with its level of risk and the reasons behind it. The local models work offline; the online check joins whenever a connection is available.
